# Code Availability

The complete computational implementation required to reproduce the simulation workflow, machine-learning energy prediction, Markov state modeling, clustering, PSO-assisted routing, baseline comparisons, ablation studies, and statistical validation is contained in this repository.

For journal resubmission, create a versioned public GitHub release and archive that immutable release in a recognized research-software repository. Insert the final public repository URL and the archival identifier into the manuscript only after the archive has been created. Do not invent an identifier before deposition.

Suggested manuscript wording after public archival:

> The source code, configuration files, reproducibility scripts, statistical-analysis workflow, and tests supporting this study are publicly available from the project repository and an immutable archived release. The archived release contains the exact version used to generate the reported results.

Before resubmission, replace this paragraph with the final GitHub URL and archive record.
